## Description

DEEPDSP-AMC is an academic Digital Signal Processing Laboratory project that classifies noisy I/Q frames into BPSK, QPSK, 8PSK, 16QAM, 2FSK, or 4FSK.

Student: Luong Hai Long, 22207056  
Class: 24DTV_DKD2  
Instructor: Huynh Quoc Thinh, M.Sc.  
Institution: VNUHCM-University of Science

The processing chain combines RRC pulse shaping, a two-ray channel, carrier-frequency and phase disturbance, timing variation, and AWGN. A 400-tree Random Forest uses 18 DSP features, while an 81,030-parameter CompactIQCNN learns from I, Q, magnitude, and phase-difference channels. Validation selects a CNN fusion weight of 0.55.

On the fixed 1,320-frame test split, Random Forest reaches 58.48% accuracy and 58.17% macro F1; CNN reaches 71.82% and 72.01%; the hybrid reaches 73.48% and 73.40%. Hybrid accuracy reaches 90.00% at 9 dB.

Scope note: all data are generated by controlled simulation. The project has not been evaluated on direct SDR captures.
