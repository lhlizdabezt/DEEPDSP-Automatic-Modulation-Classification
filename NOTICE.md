# Academic Scope and Reuse Notice

DEEPDSP-AMC is an individual academic project by Luong Hai Long (student ID 22207056) for the Digital Signal Processing Laboratory, class 24DTV_DKD2, at VNUHCM-University of Science.

The experiments use controlled synthetic baseband I/Q frames. They do not establish performance on live radio-frequency captures, software-defined radio hardware, changing field channels, or production receivers. Reported test metrics apply only to the documented dataset generation process, split, seed, models, and evaluation protocol.

Course-submission artifacts are preserved in their original language and form so that their provenance remains auditable. Repository-facing documentation and the public demonstration interface use US English.

This repository is published for educational review and portfolio evidence. Before reusing code or results in assessed work, follow the rules of your institution, cite this repository, and reproduce the experiment independently. No patent, certification, regulatory, safety, or commercial-performance claim is made.
